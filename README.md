## 项目介绍

Local Model Evaluation Tool 是一款本地大语言模型评估工具，帮助用户在本地环境中对大语言模型进行性能评估。

## 功能特点

- 支持本地大语言模型的加载与推理
- 提供多维度的评估指标分析
- 支持自定义评估任务配置
- 结果可视化展示功能
